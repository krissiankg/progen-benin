## Projets (5)

### 1. Objectif Zéro Grossesse
Campagnes de sensibilisation des adolescentes en milieu scolaire (causes, risques, conséquences, prévention). **2 732** cas de grossesses recensés année scolaire 2016-2017 (Ministère de l'Enseignement). Extension prévue aux départements les plus touchés.  
Images : `ozg-*`

### 2. Excellence Féminine
Bourses pour élèves filles excellentes — écoles primaires Borgou, Alibori, Atacora. Bourse complète (fournitures + scolarité) pour l'année suivante.  
Images : `ef-*`

### 3. Give a Smile
Parrainage besoins scolaires (fournitures, scolarité, maîtres d'études). Enfants en situations difficiles (orphelins, placés…). Écoles Borgou, Alibori, Atacora.  
Images : `gas-*`

### 4. Millennium School
Améliorer conditions de vie des élèves ; mobiliser livres, manuels, tableaux, lampes solaires.  
1ʳᵉ édition **11 oct. 2019** : kits + matériels EPP SONRI (5 km de Nikki) + construction puits d'eau.  
Image : `ms-sonri.jpg` (téléchargée depuis le site)

### 5. Enfance Épanouie
Source : [progenbenin.org/enfance-epanouie/](https://progenbenin.org/enfance-epanouie/)  
Projet d'épanouissement via le jeu (compétences sociales, intellectuelles, linguistiques). Dons de jouets / aires de jeux aux maternelles publiques rurales.  
- **2018** : aire de jeux — maternelle EPP Savi Djègo (Ouidah)  
- **2019** : jouets éducatifs (puzzles, lettres/chiffres, constructions, ballons, coloriage, voitures, poupées…)  
Images : `ee-15-1.jpg`, `ee-16.jpg`, `ee-17.jpg`  
Note : le menu officiel avait une typo `enance-epanouie` (404) ; l’URL correcte est `enfance-epanouie`.
